# Data Scraping

## Tools & Libraries
- requests, beautifulsoup4 — blog scraping
- youtube-transcript-api — YouTube transcripts
- langdetect — language detection

## How To Run
pip install requests beautifulsoup4 youtube-transcript-api langdetect
python main.py

## Limitations
- Some sites block author/date extraction
- YouTube transcripts unavailable for some videos
- YouTube publish dates require API key
